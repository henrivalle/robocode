# Changelog / Histórico de versões

## v0.1.0 (release candidate)

### English

- Build a browser-based classroom image with Classic Robocode 1.12.0 and SHA-256 verification of the installer.
- Publish noVNC on host loopback and allow distinct Compose projects for separate desktops.
- Keep robots, battles, and settings in the existing named volume while updating the runtime through the image.
- Add English and Brazilian Portuguese documentation, a contribution guide, automated checks, and a tagged source build.

### Português

- Empacota o Robocode clássico 1.12.0 para uso no navegador e verifica o SHA-256 do instalador.
- Limita o noVNC à interface local do host e permite projetos Compose distintos para desktops independentes.
- Reutiliza os robôs, batalhas e configurações do volume existente enquanto atualiza o ambiente de execução pela imagem.
- Adiciona documentação em inglês e português, guia de contribuição, testes automatizados e empacotamento de código-fonte por tag.
